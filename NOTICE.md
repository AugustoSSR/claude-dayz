# Avisos

- DayZ é marca da Bohemia Interactive. Este projeto não é afiliado a ela nem por ela endossado.
- Este repositório não redistribui código, assets, PBOs, chaves nem binários de terceiros. Mods e ferramentas
  de terceiros (por exemplo Workbench, Mikero Tools, mods de comunidade) são citados só pelo nome.
- O conteúdo é a experiência própria do mantenedor, escrita em palavras próprias.
- Ferramentas e marcas citadas só pelo nome (DayZ Tools, AddonBuilder, Mikero Tools, Steam, BattlEye). O protocolo A2S é documentado publicamente pela Valve; `docs/a2s-query-protocol.md` são notas próprias de implementação.
- Os scripts de `tools/local-build/` chamam ferramentas que você instala por conta própria; o repositório não as inclui, nem chaves de assinatura.
